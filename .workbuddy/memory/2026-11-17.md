## Email module (local-first mailbox client)
- Added `email` permission module, live `/email` navigation/roadmap entry, four-locale `email.json`, and migration `20261117010000_crm_email.sql`: per-user SMTP/IMAP accounts, AES-GCM encrypted passwords (`EMAIL_CREDENTIALS_KEY`), RLS, `deleted_at` retention purge, `lower(email)` partial indexes, deferred-join contact/account match RPCs, and access-matrix seed.
- Server bridge (`src/lib/crm/email/*` + `src/app/api/crm/email/*`) uses `imapflow`/`nodemailer`; it stores no mail bodies or attachments. UID-cursor metadata sync is bounded to 200 headers per request, with `uid-range.ts` fixing first-sync newest-window and monotonic cursor handling. Customer record links call IMAP SEARCH across enabled mailboxes and cache results without resetting the sync cursor.

Added local draft tab with open/edit/delete, reply threading via `In-Reply-To`, bulk flag/delete actions with bounded concurrency, and contact/account record buttons for both history and prefilled compose.
- Sent mail from a record prefills the recipient and writes a lightweight activity row. Roadmap copy now states clearly what is live (263/simply IMAP+SMTP, local templates, contact/account compose, timeline send logging, local drafts, reply threading) and what remains planned (M365/Gmail OAuth, merge fields, received-email timeline logging, lead/opportunity compose, last-contacted date).
